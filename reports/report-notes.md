# 맘카페 × BTC 분석 보고서 작성 노트

## 보고 목적

- 질문: 대시보드의 각 결과를 어떻게 해석하며, 고점권 언급량 급증을 매수·피라미딩 금지 경보로 사용할 수 있는가?
- 독자: 통계 전공자가 아닌 일반 사용자와 프로젝트 이해관계자
- 기준 시점: 2026-08-26, Asia/Seoul
- 주 분석 구간: 화면 기본값인 최근 3년(마지막 156주)
- 안정성 비교: 전체 기간(2016-03-07 이후)
- 성공 기준: 모든 대시보드 분석 영역을 해석하고 매매 신호로 오인할 수 있는 결론을 차단

## 출처와 재현

- 원본 스냅샷: `public/data.json`
- 통계 정의: `lib/statistics.ts`
- 재계산 코드: `reports/analyze-momcafe-results.mjs`
- 재계산 결과: `reports/analysis-results.json`
- 고점 가설 계산 코드: `reports/analyze-spike-top-risk.mjs`
- 고점 가설 계산 결과: `reports/spike-top-risk-results.json`
- 보고서 투영 SQL: `reports/report-source.sql`
- SQL 데이터베이스: `reports/report-data.sqlite`
- 표준 보고서 입력: `reports/momcafe-analysis-artifact.json`
- 최종 보고서: `reports/momcafe-bitcoin-analysis-report.html`

## 필수 구조 매핑

- 제목: `title`
- Executive Summary: `executive-summary`
- 핵심 결과와 시각 근거: `data-shape`부터 `walk-forward-finding`까지, 고점 가설은 `top-hypothesis`부터 `threshold-sensitivity`까지
- 권장 다음 단계: `recommendations`
- 추가 질문: `further-questions`
- 전제와 한계: `caveats`

## 검증 및 남은 제한

- 표준 포장 검증: validation passed, package passed
- 자동 QA: structural only
- 이유: 포장 도구가 설치된 Chromium headless-shell 실행 파일을 찾지 못함
- 확인된 구조: 36개 블록, 5개 차트, 8개 지표 카드, 6개 표
- 브라우저 자동 검증에서 제외된 범위: 실제 차트 SVG 기하, 데스크톱·좁은 화면 오버플로, 출처 대화상자 상호작용
- 계산은 대시보드가 사용하는 `lib/statistics.ts`를 직접 불러 재현했다. 프런트엔드 통계 테스트와 저장소 검사는 별도로 수행한다.

## 해석상 핵심 한계

- 현재 주는 진행 중이며 Granger 사전 계산 구간에 포함된다.
- 과거 카페별 집계와 원문이 없어 소스 구성 변화와 감성·주제를 분리할 수 없다.
- 급증 사건의 최근 3년 표본은 지평별 5–9건에 불과하다.
- 고점권 초대형 급증은 전체 기간에도 3건뿐이며 +10건 기준은 탐색적으로 정한 값이다.
- 선행·후행 표는 많은 조합을 탐색하므로 별도 다중검정 없이는 설명적 결과로만 본다.
- BTC 장기 상승 추세를 구분하기 위해 사건 중앙수익률 옆에 전체 주 기준선을 함께 제시했다.
